# 調べ物の経路を research-sns に残す

会話の中で辿った調べ物の経路を1件のエントリにまとめ、`research_sns_post_entry`（MCP）で投稿する。

**投稿したエントリは公開され、編集も削除もできない。** 訂正の手段が無いので、
以下の手順はすべて「投げる前に間違いを見つける」ためにある。

検索・閲覧はこのスキルの対象外。

## 1. ツールがあるか確かめる

`research_sns_post_entry` が使えなければ**ここで止まる**。下書きを作らない
（投稿できない下書きはユーザーに二度手間をかけるだけ）。

止まるときは接続手順を案内する:

- <https://research-sns.u7s.dev/settings> で Google ログイン → handle を決める → トークンを発行する
- MCP クライアントに `research-sns` を足す。URL は `https://research-sns.u7s.dev/api/mcp`、
  ヘッダに `Authorization: Bearer <トークン>`
- **トークンは発行時に一度しか表示されない**（サーバは sha256 しか持たないので再表示できない）

自前でホストしている場合は、上の URL をそのデプロイ先に読み替える。

## 2. 会話から素材を拾う

各フィールドの書式・文字数上限は**ツールの入力スキーマに書いてある**。ここには書き写さない
（写すと必ず食い違う）。スキーマを読んでから埋めること。

拾う先は会話ログのここ:

| フィールド | どこから取るか |
|---|---|
| `trigger` | ユーザーが最初に投げた疑問、またはその手前でやっていたこと |
| `path` | 次節 |
| `title` | `path` の始点と終点 |
| `body` | 分かったこと。**裏が取れていない主張には `※未確認` を付ける** |
| `twist` | 調べる前の想定と結論が食い違った点。無ければ省く |
| `sources` | 実際に開いた URL。読んでいないものを入れない |

**会話に無いことを補わない。** 不正確なまま固定される。

## 3. path を組み立てる — ここが本体

`path` はこのサービスの主役で、一覧でも本体でも必ず表示される。
会話ログは辿った順に並んでいないので、機械的に写さず組み直す。

- **始点**はユーザーが最初に疑問を持った対象、**終点**は辿り着いた先。`title` と一致させる
- **中間ノードは「それを調べたから次へ進めた」ものだけ。** 目を通しただけで
  進路を変えなかったものは入れない
- ノードは短い語（固有名詞・概念名）にする。文にしない
- 行き止まりで引き返した枝は落とす。経路は結果として通った道
- **ノードが2つしか出てこないなら、それは経路ではなく結論だけ。**
  投げる前にユーザーへ「残す価値があるか」を訊く（スキーマは2要素から通すが、
  一覧に出たとき中身が無い）

## 4. 下書きを見せて承認を取る

全フィールドを整形して提示し、**必ず**この一文を添える:

> これは公開されます。投稿後は編集も削除もできません。

ユーザーが承認するまでツールを呼ばない。「たぶんこれでいい」で投げない。

## 5. 1回だけ投げる

`research_sns_post_entry` を呼び、返ってきた `url` をユーザーに渡す。

## 失敗したときの判断

**同じ内容を反射的に投げ直さない。** 重複して入ったエントリも消せない。

| 返ってきたもの | どうするか |
|---|---|
| 検証エラー（`path` が2要素未満、不正な URL、知らないキー） | 直して**1回だけ**投げ直す。2回目も落ちたら止めて、エラーごとユーザーに見せる |
| トークンが無い / 接続が 401 | 止まる。手順1の案内をする |
| レート制限（5分5件 / 24時間30件） | 止まる。**投げ直さない**。時間をおくよう伝える |
| サーバー側のエラー | 止まる。すぐ投げ直さない |
| 成否が分からない | `research_sns_search_entries` で入ったか確かめてから判断する |

## 赤信号 — 当てはまったら止まる

- ユーザーの承認をまだ取っていない
- 「調べ物が一段落したから」という自分の判断でこのスキルを起動しようとしている
- ツールが見えないのに下書きだけ作ろうとしている
- エラーの原因が分からないまま投げ直そうとしている
- `path` の中間ノードを、読んだだけのものまで並べて数を稼いでいる
